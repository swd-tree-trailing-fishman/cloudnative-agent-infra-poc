🧩 コンポーネント一覧

Go 1.22

🐹 Go Backend API

Feature Toggle・OTLP計装・Sandbox Job生成を担うメインバックエンド。distroless イメージで本番同等のセキュリティ。

Django 5

🐍 Django Migration Service

Python学習用サービス。boto3でLocalStack SQSにイベント送信、OpenTelemetryでマイグレーションステップを計装。

OTLP

OTLP Collector

gRPC :4317 でスパンを受信し、Jaegerにバッチ転送。memory_limiter でOOM防止。

Jaeger

Jaeger UI

分散トレースの可視化。localhost:16686 でウォーターフォール表示。SPAN_STORAGE_TYPE: memory (PoC用)。

KEDA 2.14

KEDA Operator

SQSキュー深さを15秒間隔でポーリング。queueLength≥1 で ScaledJob を起動。maxReplicas: 5 で並列実行。

LocalStack

LocalStack SQS

本物のAWS SQS互換モック。db-migration-queue でイベントを受信・保持。

Istio 1.21

ztunnel (DaemonSet)

各NodeでL4 mTLSを自動処理。サイドカー不要でAmbient Mode。PeerAuthentication: STRICT。

Waypoint

Waypoint Proxy

L7ポリシー (AuthorizationPolicy, VirtualService) を処理。X-Regionヘッダーによるルーティング。
