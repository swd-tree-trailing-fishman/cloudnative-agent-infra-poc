ztunnel (L4 mTLS) + Waypoint Proxy (L7) のサイドカーレス通信アーキテクチャ

Istio Ambient Mesh — トラフィックフロー

Ambient Mode では、各Podにサイドカーを注入せず、 Node上の ztunnel が L4 mTLS を担い、 Waypoint Proxy が L7 ポリシーを処理します。

🔐 mTLS 証明書フロー

🔒 Namespace 分離・認可ポリシー

認可ポリシー設定一覧

  • ALLOW
    agent-infra からのトラフィック → agent-backend :8080
    AuthorizationPolicy: src.namespaces = [agent-infra, istio-system]、method = GET/POST
  • DENY
    agent-sandbox → agent-infra (全通信をブロック)
    AuthorizationPolicy: action=DENY, src.namespaces=[agent-sandbox]
  • mTLS STRICT
    agent-infra Namespace 内の全 Pod 間通信
    PeerAuthentication: mode=STRICT — ztunnel が自動でmTLS化
  • ALLOW
    agent-backend → agent-sandbox (K8s API 経由のJob作成のみ)
    Role: batch/jobs create権限 + RoleBinding で ServiceAccount に付与
