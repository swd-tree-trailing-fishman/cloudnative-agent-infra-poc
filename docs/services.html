📊 サービス依存関係グラフ

📡 API エンドポイント一覧

🐹 Go Backend API localhost:8080

  • GET /healthz liveness / readiness probe
  • GET /api/recommend Header: X-Region (JP/TW/KR)
  • POST /api/execute Body: {"command":"..."} → Sandbox Job

🐍 Django Migration API localhost:8000

  • GET /healthz ヘルスチェック
  • POST /api/migration/trigger マイグレーション直接実行 + OTLP spans
  • POST /api/migration/send-event SQS にイベント送信 → KEDA 起動
  • GET /api/migration/status SQS queue depth 確認

📡 OTLP Collector :4317 / :4318

  • gRPC :4317 OTLP gRPC receiver (Go / Django)
  • HTTP :4318 OTLP HTTP receiver
  • GET :8888/metrics Collector 自身のメトリクス

📨 LocalStack SQS :4566

  • POST /?Action=SendMessage メッセージ送信 (boto3)
  • POST /?Action=ReceiveMessage KEDA が定期ポーリング
  • POST /?Action=DeleteMessage Migration Job 完了後に削除
